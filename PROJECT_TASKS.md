# Cloud Application

## Этап развития
Усовершенствование управления облачными сервисами: контроль допустимых состояний и поддержка фильтрации.

## Требования (Requirements)
* **REQ-01**: API должно поддерживать получение списка сервисов, отфильтрованных по состоянию (параметр query `status`).
* **REQ-02**: Поле `status` в модели сервиса должно принимать только допустимые значения: `running`, `maintenance`, `stopped`.
* **REQ-03**: При отсутствии параметра фильтрации API должно продолжать возвращать полный список сервисов.
* **REQ-04**: Документация OpenAPI должна отражать новый параметр фильтрации и ограничение допустимых значений состояния.
* **REQ-05 (Самостоятельное задание)**: API должно возвращать информативное сообщение об ошибке с кодом 422 при передаче некорректного статуса в фильтре или теле запроса.
